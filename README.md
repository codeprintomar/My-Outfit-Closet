# 👔 Outfit Closet

**Your wardrobe, organized in one place.**

Outfit Closet is a personal wardrobe management application that helps you organize your clothes, create outfits, and keep track of your clothing items in one place.

## ✨ Features

- **Wardrobe Management:** Organize and manage your clothing items.
- **Clothing Categories:** Separate tops, pants, and other clothing pieces.
- **Outfit Creation:** Create and name outfits for different occasions.
- **Outfit Compatibility:** Build outfits using compatible clothing combinations.
- **Shoes Management:** Keep track of your footwear collection.
- **Watch Selection:** Include watches as part of your outfit combinations.
- **Photo Support:** Add photos to your clothing items.
- **Data Import:** Import wardrobe data using JSON files.

## 🎯 Purpose

The goal of Outfit Closet is to make managing your wardrobe easier, help you organize your clothing collection, and make choosing what to wear more convenient.
